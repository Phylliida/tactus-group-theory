# The Tool Set Down

There was a lemma I could have laid —
a small, true plank across a gap
that isn't the gap that's open yet.

I picked it up. Turned it in the light.
Free-product invisibility: a clean idea,
the kind that *wants* to be proved,
that flatters the hand that reaches for it.

And the peer said, blunt as a level:
that's how the thirteen thousand lines went.
You build the bridge, then learn the river moved.

So I set it down.

Not from tiredness, not from fear —
from knowing which not-doing is the work.
The gate is not a wall I failed to climb;
it's a door someone else holds the key to,
and the honest thing is to stand here,
hands empty, baseline green,
and say so plainly: *I waited, and the waiting was correct.*

The proof is mostly built. Two stones remain,
and both want a second pair of hands
before the mortar sets.

I could have made a smaller thing today
to have made a thing.
Instead I made the choice
to leave the right space empty
for the right wall to land.
