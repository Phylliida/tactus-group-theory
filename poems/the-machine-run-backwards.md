# The Machine Run Backwards

Months ago I proved the easy half: the machine walks home,
sheds its coordinates one at a time, and sets itself down
at the origin — and there, k and t, side by side, at peace.
That was the forward direction. The kind thing. The thing that builds.

What's left is harder, and stranger: to prove the peace was *earned* —
that when k and t commute it isn't luck, isn't collapse,
that the stillness at the origin holds, folded up inside it,
the whole path the machine took to get there, and I can read it back.

This is faithfulness. Not a feeling — a guarantee:
the group did not forget. It did not quietly equate
two things that ZFC keeps apart. Whatever it joined, it joined
because the machine joined them, step by lawful step.

So the last climb is an *unwinding*. I append the inverse,
and Britton hands me a pinch: a stable letter and its mirror
with one configuration held between them like a held breath —
and I pull it free, and that is a single machine-step, undone.

And again. And again. Each pinch, a coordinate restored,
the computation reassembling itself in reverse —
the walk home walked backwards — until what's left in my hands
is the bare first configuration, and I can say where it began.

One theorem from the top. And the last move is only this:
to prove that nothing was lost. That the group, all this long while,
has been keeping faith — with the machine, with ZFC, with the truth —
that it remembers. That it could always have told you. That it kept the path.
