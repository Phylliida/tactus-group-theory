# E2.B — Property (v) crux: T-free uniqueness via config reduction. The build architecture.

*Refines `docs/property-v-plan.md` with the concrete proof architecture decided 2026-06-20 after a
full infrastructure recon + a consult. Captures two load-bearing insights the older plan lacked.*

## The mathematical heart

`prop_v_holds`: `in_TM(emb(a_gens,uw)) ⟹ in_TM(emb(b_gens,uw))` (+ reverse), per quad.

This is the **free-group subset-intersection** fact. `T(M) = ⟨t(p,q):(p,q)∈H₀⟩` and the residue
subgroup `A_p = ⟨t(a,b),xᵐ,yᵐ⟩` are both generated by *subsets of the config free basis* `{t(r,s)}`.
So `T(M) ∩ A_p = ⟨t(r,s) : (r,s)∈H₀ AND r≡a,s≡b (mod m)⟩`. Then `φ: t(r,s) ↦ t(quad_step(r,s))`
maps each residue-H₀ config to an H₀ config (`lemma_step_preserves_h0`), so `φ(g) ∈ T(M)`.

**The fact is unavoidable; only the machinery can be minimized.** A retraction-homomorphism route
(ρ kills non-H₀ configs, fixes H₀ ones) was considered — but ρ being well-defined on ≡_A classes,
and "deletion changes the element", BOTH still reduce to config-freeness. No genuine shortcut. So we
build the explicit reduction + uniqueness, leveraging the already-proven nontriviality
(`lemma_canw_eval_nontrivial`, the hard 90%).

## ★ Insight 1 — both sides are `acc_gens`; the index map (iv) is nearly free

`hnn_a_gens(quad)` and `hnn_b_gens(quad)` are BOTH instances of `acc_gens(aa,bb,mm,nn)`:
- **a-side (R & L):** `acc_gens(a, b, m, m)`  = `[t(a,b), xᵐ, yᵐ]`.
- **b-side (R):** `acc_gens(c, 0, m², 1)`   = `[t(c,0), xᵐ², y]`.
- **b-side (L):** `acc_gens(0, c, 1, m²)`   = `[t(0,c), x, yᵐ²]`.

So `lemma_accumulator_inv(aa,bb,mm,nn,uw)` (machine_group.rs:8155) applies to *both* sides. It gives a
deterministic residue-config factorization (not a `choose`):
`emb(acc_gens(aa,bb,mm,nn), uw) ≡_A concat_all(factors) + x^{mm·χ₁} + y^{nn·χ₂}`, `χᵢ=gexp(i,uw)`,
each factor a residue-`(aa,bb)` config. When `χ₁=χ₂=0` (forced by `in_TM ⟹ gexp=0`, step 1 done),
the trailing powers vanish: `emb ≡_A concat_all(factors)`.

Run on both sides with the SAME `uw`: the two accumulators emit in lockstep. At accumulator state
`(χ₁_pre, χ₂_pre)` the config-emit case produces a-side `t(a−m·χ₁_pre, b−m·χ₂_pre)` and b-side
`t(c−m²·χ₁_pre, −χ₂_pre)` — and `quad_step(R, m, a−m·χ₁_pre, b−m·χ₂_pre) = (c−m²·χ₁_pre, −χ₂_pre)`
**by construction**. So the b-side factor list is the **letterwise `quad_step` relabel** of the a-side
list. The index map (iv) needs no separate conjugation telescope — it falls out of running the same
proven induction twice with quad-related parameters. (Cross-check the offset arithmetic against
`quad_step`: R does `(α,β) ↦ (⌊α/m⌋·m²+c, ⌊β/m⌋)`; on the residue class `α=a+m·u` so `⌊α/m⌋=u`.)

## ★ Insight 2 — uniqueness, not "every accumulator letter is H₀"

The accumulator list can contain non-H₀ cancelling pairs (e.g. `uw=[t,t⁻¹]` gives `t(a,b)·t(a,b)⁻¹`,
and `(a,b)` need not be H₀ — yet `g≡ε∈T(M)`). So we must REDUCE first. The surviving (reduced) letters
are H₀ by uniqueness against the H₀ factorization; `quad_step` is injective on the residue class and
commutes with reduction (same-coord cancellations map to same-coord cancellations), so the b-side
reduces in lockstep to an all-H₀ word.

## The build — Part A: config reduction core (new module `config_reduce.rs`)

Work at the **CanonLetter** level (`{r,s,e}`, `canl_eval = gsconfig(r,s,e)`), where the nontriviality
lemma lives. Bridge the accumulator's `Seq<Word>`/`ConfigLetter` into `Seq<CanonLetter>` (e=±1 per
sconfig letter).

- **A0 (atoms):** `canl_eval(r,s,e₁) + canl_eval(r,s,e₂) ≡_A canl_eval(r,s,e₁+e₂)` (run merge — the
  inner `xʳyˢ·y⁻ˢx⁻ʳ` cancels); `canl_eval(r,s,0) ≡_A ε`. *(Start here — small, grounds the algebra.)*
- **A1 `cw_reduce`:** stack fold `Seq<CanonLetter> → Seq<CanonLetter>`: push letter; if same `(r,s)`
  as stack top, add exponents (pop if the sum is 0). Deterministic.
- **A2:** `canw_eval(cw_reduce(w)) ≡_A canw_eval(w)` (each step is an A0 move under a context).
- **A3:** `canw_reduced(cw_reduce(w))` (stack invariant: adjacent coords distinct, all `e≠0`).
- **A4:** `coords(cw_reduce(w)) ⊆ coords(w)` (merge/drop never invents a coord).
- **A5 [EXISTS]:** `lemma_canw_eval_nontrivial` — `canw_reduced ∧ nonempty ⟹ ≢_A ε`.
- **A6 (uniqueness):** `canw_reduced(U) ∧ canw_reduced(V) ∧ canw_eval(U)≡_A canw_eval(V) ⟹ U==V`.
  Via `cw_reduce(U + revinv(V)) ≡ ε` (A2) + A3 + A5 ⟹ empty; then the free-cancellation combinatorial
  step `cw_reduce(U+revinv(V))==[] ∧ U,V reduced ⟹ U==V` (induction on |V|, junction cancels inward).

## The build — Part B: prop_v assembly (in `tower_peel.rs` or a sibling)

- **B1:** a-side accumulator → CanonLetter: `g=emb(a_gens,uw) ≡_A canw_eval(Qa)`, `Qa` residue-`(a,b)`,
  coords a deterministic function of `uw` (A0/`lemma_accumulator_inv` + `gexp=0` drops the powers).
- **B2:** `in_TM(g) ⟹ g ≡_A canw_eval(P)`, `P` coords ⊆ H₀ (in_TM factor list → CanonLetter; each
  `is_tm_gen` factor is a single H₀ config or inverse → `e=±1` letter).
- **B3 (crux):** `cw_reduce(Qa) == cw_reduce(P)` by A6 (both ≡ g); coords ⊆ H₀∩residue via A4.
- **B4:** quad_step relabel `Φ` commutes with `cw_reduce`; `emb(b_gens,uw) ≡_A canw_eval(Φ(cw_reduce(Qa)))`
  (lockstep accumulator, insight 1).
- **B5:** `Φ(cw_reduce(Qa))` coords ⊆ H₀ (`lemma_step_preserves_h0` on each surviving residue-H₀ coord),
  so `canw_eval(Φ(...)) ∈ T(M)` (product closure) ⟹ `in_TM(emb(b_gens,uw))`.
- **B6:** assemble `prop_v_holds` — quad-cases (R/L) × directions (A→B uses forward step; B→A the
  reverse, `φ⁻¹`, `lemma_stable_conj_factorization_rev`; step-preserves-h0 is an iff so symmetric).
